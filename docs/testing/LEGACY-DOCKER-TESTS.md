# Legacy Docker tests: quarantine and migration inventory (M0-11)

These tests predate the isolation guard (`test/dockerguard`). They create, rename and remove containers through `testcontainers` or a `client.FromEnv` client, i.e. on **whatever daemon the environment or default socket selects**. They are therefore excluded from every normal build by the build tag `dockerint_legacy` and **must not be run** until migrated. Migration = obtain the client through `dockerguard.Main`/`Current`, label everything with `Session.LabelArgs()`, and route `testcontainers` to the guarded endpoint (it reads `DOCKER_HOST`/`TESTCONTAINERS_HOST_OVERRIDE`; the guard's runner unsets ambient Docker variables and must set both explicitly).

**Status: NOT migrated.** Coverage that existed only here is currently *not executed anywhere*. That is a regression in executed coverage that M0-11 must close before M0 is complete.
